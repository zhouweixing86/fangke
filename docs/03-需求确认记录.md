## 3. 现场验证前置项（W0）

以下 8 项为**硬件事实**，无法通过沟通确认，必须在开发前现场验证。详见《W0 现场验证清单》。

| 编号 | 验证项 | 若结论为否的影响 | 优先级 |
|---|---|---|---|
| V1 | 白名单按**证件号**匹配（而非人脸特征） | 若按人脸 → 访客必须采照片，核心设计失效 | 最高 |
| V2 | 固件支持在线比对接口 | 现场登记失去在线兜底 | 高 |
| V3 | 设备真正执行有效期 | 访客名单永不过期，安全事故 | 最高 |
| V4 | 本地名单与在线比对能否混合 | 影响兜底路径 | 中 |
| V5 | 设备人员容量与下发耗时 | 影响清理策略与下发窗口 | 中 |
| V6 | **二维码在线校验模式**是否可用，且与刷证/刷脸共存 | 动态二维码方案不可行，或与断网名单冲突 | 最高 |
| V7 | 磁吸门电气行为（断电/断网） | 影响验收与告知书 | 中 |
| V8 | **入口/出口双设备**方向配置与上报是否可靠 | 无法准确记录进场与离场 | 高 |

> **决策点**：V1 若为"按人脸特征匹配"，需立即暂停开发，重新评估访客照片采集方案与合规方案。
