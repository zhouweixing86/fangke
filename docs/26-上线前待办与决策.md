## 8. 异地备份运维命令

```bash
# 立刻跑一次（生产机）
sudo systemctl reset-failed fangke-backup && sudo systemctl start fangke-backup
sudo tail -n 20 /opt/fangke/logs/backup.log          # 末尾应是「===== 备份完成 =====」

# 看异地副本（测试机 47.103.158.76）
ls -lh /data/fangke-backup/db /data/fangke-backup/media
for f in /data/fangke-backup/db/*.gz; do gzip -t "$f" && echo "OK $f"; done

# 恢复演练（测试机，导入后记得删临时库）
docker exec fangke-mysql mysql -uroot -p"$PW" -e "CREATE DATABASE fangke_restore_chk"
gunzip -c /data/fangke-backup/db/<file>.sql.gz | sed '/^CREATE DATABASE/d; /^USE /d' \
  | docker exec -i fangke-mysql mysql -uroot -p"$PW" fangke_restore_chk
```

> 异地密钥：生产机 `/root/.ssh/id_ed25519_fangke_backup`（只读式只写 `/data/fangke-backup`）；本机与远端都按 14 天滚动清理（`rsync --delete` 保证两端一致）。
