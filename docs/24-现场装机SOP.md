## 1. 车闸相机（进门 / 出门各一台，逐台做）

2. **高级设置 → 平台配置 →「标准协议（MQTT）」**，填写：

   | 平台地址 | `58.87.99.249` |

   | 云平台用户密码 | `mAX1nJyPpviu0cTeo49Sxa6K` |

## 3. 装完之后由平台侧做（通知我即可，不用现场操作）

1. 设备管理里把两台相机分配到 **门点 + 方向（入口/出口）**，行人终端分配 **门点 + 方向**

## 5. 常见故障对照表

| 现象 | 最可能原因 | 处理 |
|---|---|---|
| 相机后台能打开，但平台里一直离线 | 第 1 节第 2 步的配置丢了/没保存 | 重填 4 项 + 3 个开关 → 保存所有 |
| 相机识别到车牌，闸不开 | 相机本地「白名单控制模式」被改成"脱机后自动开闸" | 调试向导 → 白名单配置 → 改成 **自动开闸**；然后叫我跑强制同步 |
| 相机离线，怎么都连不上 | 现场网络出不去（防火墙挡 1833） | 现场确认能访问 `58.87.99.249:1833`（用手机 4G 热点试最快） |
| 行人终端不发心跳 | 平台地址填成了带 `/openapi/v1` 的地址，或没重启 | 地址只填根、保存后 **重启设备** |
| 终端人数与平台不一致 | 终端里有历史残留人员 | 叫我执行「清理残留」 |
| 二维码扫码提示"未授权" | 证件/二维码功能未下发地址 | 叫我执行「下发二维码核验地址」 |

2. 拍三张照发我：相机后台首页（看连接状态）、平台配置页（看 4 项）、平台设备列表（看在线/心跳）
